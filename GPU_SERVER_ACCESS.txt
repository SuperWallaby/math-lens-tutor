2. SSH 접속
================================================================================

2-1. ~/.ssh/config 별칭 (권장)

  Host lab-master
    HostName 218.39.226.104
    User user
    Port 22
    IdentityFile ~/.ssh/id_ed25519
    IdentitiesOnly yes

  Host lab-worker
    HostName 10.10.10.14
    User user
    Port 22
    IdentityFile ~/.ssh/id_ed25519
    IdentitiesOnly yes
    ProxyJump lab-master

2-2. 접속 명령

  마스터:
    ssh lab-master

  워커 (ProxyJump, 한 번에):
    ssh lab-worker

  워커에서 원격 명령 실행:
    ssh lab-worker 'hostname'
    ssh lab-worker 'curl -sS http://127.0.0.1:9000/health'

2-3. config 없을 때 (명시적)

  마스터:
    ssh -i ~/.ssh/id_ed25519 user@218.39.226.104

  마스터 경유 워커 (수동):
    ssh user@218.39.226.104
    ssh user@10.10.10.14

2-4. SSH 포트 포워딩 (개발·터널)

  로컬 PC에서 워커 API를 직접 붙일 때:
    ssh -L 9000:10.10.10.14:9000 user@218.39.226.104

  터널 유지 중 로컬에서:
    http://127.0.0.1:9000/health

  이 경우 local_gateway/.env:
    REMOTE_BASE_URL=http://127.0.0.1:9000

2-5. SSH 키

  개인키: ~/.ssh/id_ed25519
  공개키는 마스터·워커 양쪽 ~/.ssh/authorized_keys 에 등록 필요.

6. 로컬 게이트웨이 기동
================================================================================

  python3 -m venv .venv
  .venv/bin/pip install -r requirements.txt
  cp .env.example .env    # REMOTE_BASE_URL 설정
  .venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8080

  생성 이미지 저장:
    local_gateway/artifacts/<job_id>.png
