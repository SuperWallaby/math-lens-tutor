# 우열 화면 맞추기: 탭 화면에 파란 무대

- 날짜: 2026-10-19
- 상태: 승인 (2026-10-19, 1단계 학생부터). 같은 날 범위를 「탭 화면만」으로 줄임(사용자 결정, 아래 1장).
- 브랜치: `renovation`
- 앞선 스펙: `2026-10-17-liquid-glass-renewal-design.md`. 그 스펙의 「파란 무대는 홈에만」 규칙을 「탭 화면 위쪽에 파란 무대」로 바꾼다.
- 시안: https://claude.ai/artifact/F8M8nCT4xnYMhGzFBDkdPf (사용자가 고른 안: 「전부 파란 무대」. 이 문서는 그중 탭 화면 부분만 쓴다)

## 1. 왜

사용자는 홈 리뉴얼 뒤 다른 탭이 홈과 따로 논다고 느꼈다. 홈 스타일 전부를 탭바로 여는 다른 탭 화면에 가져가기로 했다. 홈 스타일은 파란 무대, 큰 흰 제목, 무대 위 유리 카드, 흰 주 버튼이다. 범위는 학생 탭만이 아니라 학부모·선생님 탭까지다.

**범위를 줄인 이유**: 처음 안은 밀어서 여는 화면(분석, 풀이, 업로드 등)까지 무대를 까는 것이었다. 사용자가 이렇게 바로잡았다: 「메인탭처럼 다른 앱바 탭들 디자인을 바꾸라는 거였고, 로그인 디자인은 그전에 보여준 시안으로 할 거야」. 그래서 범위는 탭 화면이다.

**성공 기준**

1. 학생·학부모·선생님 누구로 들어와도, 탭바의 어느 탭을 열어도 위쪽이 홈과 같은 파란 무대다.
2. 무대의 짜임새(제목 위치·크기, 유리 카드·칸, 버튼)가 탭마다, 역할마다 같은 규칙을 따른다.
3. 기존 기능과 데이터는 그대로다. 보여주는 숫자는 실제 데이터로만 채운다.

**작업 순서** (사용자 결정: 학생 먼저, 학부모는 그다음)

1. **1단계 · 학생 탭**
   - 2장 규칙, 4장 공통 코드, 3.1의 학생 탭(훈련, 성장, 설정).
   - 설정과 진도는 학부모·선생님도 같은 코드를 쓰므로 이 단계에서 같이 바뀐다. 그래서 그 탭에 들어가는 자녀 고르기 칩의 무대용 모양(2장)도 이 단계에서 만든다(내 판단).
   - 끝나면 시뮬레이터·웹에서 사용자가 보고 확인한다.
2. **2단계 · 학부모·선생님 전용 탭**
   - 3.2, 3.3.
   - 1단계 확인 뒤 따로 계획을 세운다. 1단계에서 바뀐 것을 보고 이 부분을 고칠 수 있다.

**하지 않는 것**

- 밀어서 여는 화면은 지금 모습 그대로 둔다: 분석, 풀이, 업로드, 세트 결과, 학습 통계, 연습 준비, 학부모 설명 상세, 학생 연결.
- 로그인·온보딩: 다른 세션이 맡는다. 사용자가 고른 예전 시안(A, 안개색 바탕, 무대 없음)으로 간다. 앱 셸 앞에 뜨는 막는 화면 두 개도 그쪽 일이다(「자녀 연결」 필수 `GuardianLinkRequiredScreen`, 「교사 계정 준비 중」 `TeacherClosedScreen`).
- 라이트 앱 첫 화면(`LiteHomeScreen`): 탭 화면이 아니다.
- 쓰지 않는 화면: `HomeScreen`, `ParentGrowthScreen`, `StudentCodeScreen`(어디서도 열리지 않는다).
- 새 API나 데이터 필드
- 다크 모드
- 역할 색(학부모 초록, 선생님 보라)으로 무대를 칠하는 것. 무대는 역할과 상관없이 파랑이다.

**실패로 보는 것**

- 무대에 실제 데이터가 아닌 숫자가 보이는 것
- 탭을 오갈 때 무대 높이·제목 위치가 탭마다 들쭉날쭉한 것

## 2. 탭 무대

- 배경
  - 홈과 같다: 165° `#5EB7EB` → `#2A72E5` → `#1E46AA`, 아래 모서리 32, 번짐 장식 없음.
  - 무대는 콘텐츠와 함께 스크롤된다(위에 고정되지 않는다).
  - 상태바 글자는 무대 위에서 흰색이다.
- 여백: 위 = 안전 영역 + 14, 좌우 18.
- 제목과 설명
  - 큰 제목: 24/700 흰색, 홈 인사 문장과 같은 그림자.
  - 그 아래 설명 한 줄: 13.5/600 흰색 86%. 설명은 없어도 된다.
- 오른쪽 자리: 제목 줄 오른쪽에 무대용 유리 원 버튼(36)을 하나 둘 수 있다. 성장 탭의 「학습 통계」가 쓴다.
- 자녀 고르기(`StudentPicker`)
  - 학부모 탭에 있으면 제목·설명 아래, 무대 위에 둔다.
  - 지금처럼 현재 자녀 칩 하나 + 꺾쇠(눌러서 시트로 고름) + 자녀 추가 버튼이다.
  - 모양만 무대용으로 바꾼다: 칩은 유리 알약에 흰 글자, 자녀 추가는 유리 원에 흰 + 아이콘(초록 대신).
- 그 아래 무대용 유리 카드(`GlassPreset.onBlue`)에 요약과 주 버튼, 또는 유리 칸(라벨 + 숫자)을 둔다.
- 무대 아래는 지금처럼 흰 카드 목록이다.

**버튼과 유리**

- 무대 위 주 버튼: 흰 버튼 + 파란 글씨(`AppButtonStyles.white()`).
- 무대 아래 주 버튼: 연파랑(`AppButtonStyles.soft()`).
- 무대 위 카드·칸·알약·원은 무대용 유리. 무대 아래는 흰 카드. 떠 있는 층(탭바, 시트, 팝업) 규칙은 그대로.
- 아이콘은 `AppIcons`(MingCute)만.

## 3. 탭별 무대 내용

### 3.1 학생 (탭: 홈, 훈련, 성장, 설정. 홈은 이미 끝남)

| 탭 | 무대 내용 (시안 기준) | 무대 아래 |
|----|----------------------|-----------|
| 훈련 (기록 있음) | 「훈련」 / 「막힌 개념만 모아서 다시 풀어봐요」.<br>유리 카드: 지금의 복습 세트 카드 내용(개념, 누적 오답) + 흰 주 버튼(분기는 7장).<br>유리 칸 2개: 「풀 문제」(피드 문제 수), 「다시 맞힘」(`relearnedCount`, N건) | 「풀 문제」 목록(지금의 피드 카드) 등 기존 내용 |
| 훈련 (빈 상태) | 같은 제목·설명.<br>유리 카드: 「아직 훈련할 문제가 없어요」 + 「숙제를 찍으면 막힌 개념이 여기에 모여요.」 | 예시 줄, 「가운데 카메라로 시작해요」 |
| 성장 | 「내 진도」 / 「2022 개정 교육과정 · 중1」. 시작 전이면 설명 줄은 「숙제를 찍으면 그 단원부터 채워져요」.<br>유리 알약 학년 선택(고른 것은 흰색 + 진파랑 글자).<br>유리 칸 2개: 「끝낸 단원 n / N」(진행률 100인 단원 수), 「정답률」(`stats.accuracy`).<br>오른쪽 자리에 「학습 통계」 | 단원 목록 |
| 설정 | 「설정」.<br>프로필 줄: 사진 또는 이름 첫 글자, 이름, 학년 · 학교.<br>학생이면 유리 카드 「학생 코드」 + 흰 「복사」 | 알림·계정 등 기존 묶음 |

### 3.2 학부모 (탭: 홈, 설명, 이번 주, 진도, 설정) — 2단계. 진도·설정은 1단계에서 같이 바뀜

| 탭 | 무대 내용 | 무대 아래 |
|----|-----------|-----------|
| 홈 (`ParentHomeScreen`) | 「안녕하세요, 이름님」 / 「오늘은 이렇게 도와주시면 좋아요」.<br>자녀 고르기 칩.<br>유리 카드: 오늘의 부모 코칭(지금 카드의 라벨, 질문, 상황). 코칭이 없으면 지금 문구 「(자녀)가 문제를 풀면, 대화용 코칭 질문이 여기에 표시됩니다.」<br>유리 칸 2개: 「이번 주 정답률」(`stats.accuracy`, 변화량이 0이 아니면 작은 글씨로 +n%), 「푼 문제」(`stats.totalProblems`) | 「틀린 문제, 이렇게 도와주세요」, 「오늘 할 일」 |
| 홈 · 자녀 없음 (게스트) | 「자녀를 연결해 주세요」 / 「고유번호 6자리를 모두 입력하면 자동으로 연결됩니다.」 | 지금의 연결 칸과 안내 |
| 설명 (`ParentExplainScreen`) | 「이해하기 쉬운 설명」 / 「학부모가 자녀에게 바로 설명할 수 있도록 정리했어요.」<br>자녀 고르기 칩 | 틀린 문제 카드 목록, 빈 안내 |
| 이번 주 (`ParentReportScreen`) | 「(주 라벨) · 부모 가이드」 / 기간(`report.period`).<br>자녀 고르기 칩.<br>코칭 카드가 있으면 유리 카드로 | 이번 주 체크리스트, 학습 루프 · 부모 역할, 단원 이해도 |
| 진도 (`StudentProgressScreen`, 학부모 보기) **1단계** | 학생 성장 무대와 같은 짜임새.<br>「교육과정 진도」 / 「단원을 눌러 자녀에게 어떻게 도와줄지 확인하세요」.<br>자녀 고르기 칩, 학년 알약, 유리 칸 2개(끝낸 단원, 정답률).<br>오른쪽 자리에 「학생 학습 통계」 | 단원 목록(눌러서 부모 가이드) |
| 설정 **1단계** | 학생 설정과 같은 무대.<br>자녀가 연결돼 있으면 지금처럼 자녀 고르기 칩(무대 위).<br>학생 코드 카드는 없다 | 「학생 연결 관리」 등 기존 묶음 |

연결 안 된 게스트 학부모가 설명·이번 주·진도 탭을 열 때 나오는 안내(`GuardianLearningGate`)도 같은 탭 무대를 쓴다(2단계).
- 제목은 그 탭 이름(「틀린 문제 설명」, 「이번 주 할 일」, 「교육과정 진도」).
- 설명은 「고유번호 6자리를 모두 입력하면 자동으로 연결됩니다.」
- 연결 칸은 무대 아래.

### 3.3 선생님 (탭: 홈, 학생, 반진도, 설정) — 2단계. 설정은 1단계에서 같이 바뀜

지금 실제 선생님 계정은 「교사 계정 준비 중」 화면에서 막히고, 이 탭들은 게스트 선생님으로만 들어온다. 그래도 같은 규칙으로 맞춘다.

| 탭 | 무대 내용 | 무대 아래 |
|----|-----------|-----------|
| 홈 (`TeacherHomeScreen`) | 「안녕하세요, 이름님」(이름 없으면 「선생님」) / 기관 이름(있을 때만).<br>유리 칸 3개: 「담당 학생」, 「즉시 관리」(n명), 「반 평균」(n%). 지금 보라 상자의 숫자 그대로다.<br>흰 「학생 추가」: 지금의 학생 추가 줄, 학생 코드 입력으로 이동 | 「즉시 관리 필요」 경고, 「전체 학생 현황」 |
| 학생 (`TeacherStudentDetailScreen`) | 고른 학생 이름(제목) / 학생 코드(설명), 이름 첫 글자 원.<br>유리 칸 2개: 「이번 주 정답률」, 「푼 문제」.<br>고른 학생이 없으면 제목 「학생」, 설명 「홈 탭에서 학생을 선택하면 상세 현황을 볼 수 있습니다.」 | 약점 개념, 최근 피드백 |
| 반진도 (`TeacherClassProgressScreen`) | 「반 진도 현황」(설명 없음) | 단원 평균, 지도 추천, 선택 학생(「진도 보기」) |
| 설정 **1단계** | 학부모 설정과 같다(자녀 고르기 칩은 지금처럼 없음) | 기존 묶음 |

무대로 올리는 문구와 숫자는 그 탭이 지금 보여주는 것만 쓴다. 새로 지어내지 않는다.

## 4. 코드 구조

- `widgets/page_stage.dart` (새 파일)
  - 무대 그림: `PageStage.tab({title, subtitle, trailing, children})`, 무대용 유리 카드·칸·알약·원.
  - 스크롤 틀: 상태바 띠, 목록 여백.
  - 홈의 `HomeStage`는 배경과 글자 스타일을 이 파일과 공유한다(동작은 그대로).
- 무대 위 유리 칸(라벨 + 숫자)은 홈의 통계 칸과 같은 위젯으로 모은다. 칸 수는 2개 또는 3개(선생님 홈).
- 탭 화면은 `GlassSurface(`를 직접 쓰지 않고 `page_stage.dart` 부품만 쓴다. 디자인 규칙 테스트(`test/design_rules_test.dart`)의 허용 목록에는 `page_stage.dart`만 더한다.
- 2단계:
  - 학부모 탭의 공통 틀(`ParentLinkedScrollView`, `widgets/parent_tab_scaffold.dart`)이 맨 위에 그리는 자녀 고르기 칩은 무대 안으로 옮긴다.
  - 연결 안 된 학부모 안내(`GuardianLearningGate`)도 탭 무대로 그린다.

## 5. 앞선 스펙과 문서

- 앞선 스펙 3장의 「예외는 홈 상단의 파란 무대 하나뿐」을 「탭 화면 위쪽의 파란 무대」로 바꾼다. `DESIGN.md`, `.cursor/rules/design.mdc`도 같이 고친다.
- 로그인·온보딩 세션에는 알렸다. 무대는 앱 안 탭 화면용이고, 로그인은 예전 시안(A)으로 간다.

## 6. 먼저 할 일

기준 커밋은 끝났다(`d87d70d`, MingCute 아이콘 전환, 흑백 탭바와 모션). 이 문서와 계획을 커밋한 뒤 시작한다.

## 7. 내 판단으로 정한 것 (검토자 질문에 대한 답)

- **상태바와 스크롤**
  - 무대가 보이는 동안 상태바 글자는 흰색이다(`PageStage`가 `AnnotatedRegion<SystemUiOverlayStyle>`을 가진다).
  - 무대가 스크롤되어 사라지면 홈처럼 `GlassStatusBarBand`가 나타나고 글자는 검정이 된다.
  - 훈련·성장의 `GlassScrollEdge`는 이 띠로 바꾼다(홈과 같은 동작).
- **오른쪽 버튼 자리**: 성장 탭의 학습 통계 버튼(학부모는 「학생 학습 통계」)이 무대 제목 줄 오른쪽 유리 원으로 간다. 누르면 지금처럼 학습 통계 화면이 열린다. 그 화면 모습은 그대로다.
- **설정**
  - 무대의 프로필 사진은 지금처럼 눌러서 바꿀 수 있다(편집 표시 유지).
  - 「기본 정보 수정」은 무대 안 흰 작은 버튼으로 둔다.
  - 역할 칩과 게스트 안내는 무대 아래 첫 줄에 둔다.
- **불러오는 중·오류·빈 상태**: 무대(제목과 설명)는 항상 그린다. 스켈레톤·오류·빈 안내는 무대 아래에 둔다. 유리 칸은 데이터가 올 때까지 그리지 않는다(0으로 채우지 않는다).
- **훈련 무대 카드**: 지금 화면의 위쪽 카드 분기를 그대로 무대로 올린다.
  - 복습 세트가 있으면 흰 「5문제 세트로 복습」.
  - 이어서 할 세트가 있으면 흰 「이어서 복습하기」.
  - 피드만 있으면 「풀 문제 N개가 준비됐어요」.
  - 기록은 있는데 훈련할 게 없으면 「막힌 문제를 다 풀었어요.」
  - 유리 칸은 「풀 문제」(피드 문제 수)와 「다시 맞힘」(`relearnedCount`, N건). 카드 본문에는 다시 맞힘 숫자를 다시 쓰지 않는다.
- **숫자 정의**: 「끝낸 단원 n / N」의 N은 지금 고른 학년 구간의 단원 수다.
- **학부모·선생님 홈**: 학생 홈의 큰 앱 아이콘·날짜 무대(`HomeStage`)는 학생 홈에만 둔다. 학부모·선생님 홈은 인사 문장을 제목으로 쓰는 탭 무대로 한다. 학생 홈은 「오늘 할 공부」가 중심이라 무대가 크고, 학부모·선생님 홈은 코칭·숫자가 중심이라 다른 탭과 같은 높이가 맞다고 봤다.
- **역할 색**: 무대 위는 역할과 상관없이 파랑·흰색·유리만 쓴다.
  - 학부모 코칭 카드의 초록 강조와 선생님 홈의 보라 상자는 무대로 올라가면서 유리 카드·유리 칸이 된다.
  - 무대 아래의 역할 색(설정의 역할 칩, 「즉시 관리 필요」의 경고 색 등)은 그대로 둔다.
- **학부모 숫자**: 지금 홈의 한 줄 요약(「자녀 · 이번 주 n% · n문제」)을 유리 칸 2개로 나눈다. 숫자는 같은 `stats` 값이다.
- **선생님 학생 추가**: 무대의 흰 「학생 추가」는 지금 줄과 같은 곳(학생 연결 화면)으로 간다.
- **코칭 카드의 「채점 포인트」**: 지금 카드에 있는 내용이라 빼지 않는다. 무대 유리 카드 안에서 한 겹 더 옅은 칸(흰색 14% 정도)에 그대로 둔다.
- **불러오는 중·오류일 때 제목**
  - 데이터가 와야 생기는 제목은 그 전까지 탭 이름을 쓴다.
  - 이번 주는 「이번 주 할 일」(지금 안내 화면 제목)이고, 설명은 없다.
  - 선생님 홈은 이름이 세션에 있으니 「안녕하세요, 이름님」을 바로 쓰고, 기관 이름만 나중에 붙는다.
- **선생님 학생 탭 새로고침**
  - 지금은 처음 한 번만 불러온다. 홈에서 학생을 바꾸면 이름만 바뀌고 숫자는 그대로다.
  - 무대에 이름과 숫자가 나란히 서면 서로 다른 학생 것이 보이게 된다. 그래서 고른 학생이 바뀌면 다시 불러오게 고친다(동작 변경은 이것 하나).
- **선생님 반진도의 「진도 보기」**: 진도 화면을 밀어서 연다. 같은 탭 무대로 보이고, 지금처럼 따로 뒤로가기 버튼은 없다(2단계에서 다시 본다).
