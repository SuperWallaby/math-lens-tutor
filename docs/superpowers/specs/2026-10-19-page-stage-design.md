# 우열 화면 맞추기: 모든 화면에 파란 무대

- 날짜: 2026-10-19
- 상태: 승인 (2026-10-19, 1단계 학생부터)
- 브랜치: `renovation`
- 앞선 스펙: `2026-10-17-liquid-glass-renewal-design.md` (이 문서가 그 스펙의 「파란 무대는 홈에만」 규칙을 바꾼다)
- 시안: https://claude.ai/artifact/F8M8nCT4xnYMhGzFBDkdPf (사용자가 고른 안: 「전부 파란 무대」)

## 1. 왜

사용자는 홈 리뉴얼 뒤 다른 화면이 「전부 다」 홈과 따로 논다고 느꼈다. 홈 스타일 전부(파란 무대, 큰 흰 제목, 무대 위 유리 카드, 흰 주 버튼)를 앱의 모든 화면에 가져가기로 했다. 3단계 안(파랑을 결과 화면에만)도 비교했지만 「전부 파란 무대」를 골랐다. 범위는 학생 화면만이 아니라 「학부모 화면까지 전부」(학부모·선생님 전용 화면 포함)로 정했다.

**성공 기준**

1. 학생·학부모·선생님 누구로 들어와도, 앱 안 어느 화면을 열어도 위쪽이 홈과 같은 파란 무대다.
2. 무대의 짜임새(제목 위치·크기, 유리 카드, 버튼, 뒤로가기)가 화면마다, 역할마다 같은 규칙을 따른다.
3. 기존 기능과 데이터는 그대로다. 보여주는 숫자는 실제 데이터로만 채운다.

**작업 순서** (사용자 결정: 학생 먼저, 학부모는 그다음)

1. **1단계 · 학생**: 2장 무대 규칙, 4장 공통 코드(`PageStage`, 유리 칸), 3.1 학생 화면 전부. 학생·학부모·선생님이 같이 쓰는 화면(설정, 학습 통계, 진도)은 코드가 하나라 이 단계에서 같이 바뀐다. 그 화면들이 학부모에게 깨져 보이지 않도록, 그 화면에 들어가는 자녀 고르기 칩의 무대용 모양(2.1)도 이 단계에서 만든다(내 판단). 1단계가 끝나면 시뮬레이터·웹에서 사용자가 보고 확인한다.
2. **2단계 · 학부모·선생님·라이트**: 3.2~3.5. 1단계 확인 뒤 따로 계획을 세운다. 1단계에서 바뀐 것을 보고 이 부분을 고칠 수 있다.

**하지 않는 것**

- 로그인·온보딩 화면: 다른 세션이 디자인 중이다. 로그인 직후 앱 셸 앞에 뜨는 막는 화면(「자녀 연결」 필수 화면 `GuardianLinkRequiredScreen`, 「교사 계정 준비 중」 `TeacherClosedScreen`)도 같은 흐름이라 그쪽에 맡긴다. 이 문서의 무대 규칙을 그쪽에 알린다.
- 쓰지 않는 화면: `HomeScreen`, `ParentGrowthScreen`, `StudentCodeScreen` (어디서도 열리지 않는다)
- 새 API나 데이터 필드
- 다크 모드
- 역할 색(학부모 초록, 선생님 보라)으로 무대를 칠하는 것. 무대는 역할과 상관없이 파랑이다.

**실패로 보는 것**

- 무대에 실제 데이터가 아닌 숫자가 보이는 것
- 무대 때문에 문제 풀이 화면에서 문제가 아래로 밀려 첫 화면에 안 보이는 것

## 2. 무대 두 가지

모든 무대는 홈과 같은 배경을 쓴다: 165° `#5EB7EB` → `#2A72E5` → `#1E46AA`, 아래 모서리 32, 번짐 장식 없음. 무대는 콘텐츠와 함께 스크롤된다(위에 고정되지 않는다). 상태바 글자는 무대 위에서 흰색이다.

### 2.1 탭 무대 (탭바에서 바로 여는 화면: 학생 홈을 뺀 모든 탭, 라이트 앱 첫 화면)

- 위 여백: 안전 영역 + 14. 좌우 18.
- 큰 제목: 24/700 흰색(홈 인사 문장과 같은 그림자). 그 아래 설명 한 줄: 13.5/600 흰색 86%. 설명은 없어도 된다.
- 학부모 화면에서 자녀 고르기(`StudentPicker`)가 있으면 제목·설명 아래 무대 위에 둔다. 지금처럼 현재 자녀를 보여주는 칩 하나 + 꺾쇠(눌러서 시트로 고름) + 자녀 추가 버튼이다. 모양만 무대용으로 바꾼다: 칩은 유리 알약에 흰 글자, 자녀 추가는 유리 원에 흰 + 아이콘(초록 대신).
- 그 아래 무대용 유리 카드(`GlassPreset.onBlue`)에 요약과 주 버튼, 또는 유리 칸(라벨 + 숫자).
- 무대 아래는 지금처럼 흰 카드 목록.

### 2.2 흐름 무대 (밀어서 여는 화면: 분석 결과, 풀이, 업로드, 세트 결과, 학습 통계, 설명 상세, 학생 연결)

- 머리줄: 왼쪽 무대용 유리 원형 뒤로가기(36, 흰 화살표), 가운데 작은 제목 15/700 흰색. Material `AppBar`는 쓰지 않는다.
- 필요하면 그 아래 큰 결론 문장(22~24/700 흰색)과 유리 카드, 흰 주 버튼.
- 풀이 화면은 무대를 낮게: 머리줄 + 진행 막대 + 주제 한 줄. 문제 카드는 무대 아래 첫 화면에 보여야 한다.

### 2.3 버튼과 유리

- 무대 위 주 버튼: 흰 버튼 + 파란 글씨(`AppButtonStyles.white()`).
- 무대 아래 주 버튼: 흐름 화면은 파란 유리(`GlassPrimaryButton`), 탭 화면은 연파랑(`AppButtonStyles.soft()`).
- 무대 위 카드·칸·알약은 무대용 유리. 무대 아래는 흰 카드. 떠 있는 층(탭바, 시트, 팝업) 규칙은 그대로.
- 아이콘은 `AppIcons`(MingCute)만.

## 3. 화면별 무대 내용

### 3.1 학생

| 화면 | 무대 | 무대 내용 (시안 기준) | 무대 아래 |
|------|------|----------------------|-----------|
| 훈련 (기록 있음) | 탭 | 「훈련」 / 「막힌 개념만 모아서 다시 풀어봐요」. 유리 카드: 지금의 복습 세트 카드 내용(개념, 누적 오답) + 흰 주 버튼(분기는 7장). 유리 칸 2개: 「풀 문제」(피드 문제 수), 「다시 맞힘」(`relearnedCount`, N건) | 「풀 문제」 목록(지금의 피드 카드) 등 기존 내용 |
| 훈련 (빈 상태) | 탭 | 같은 제목/설명. 유리 카드: 「아직 훈련할 문제가 없어요」 + 「숙제를 찍으면 막힌 개념이 여기에 모여요.」 | 예시 줄, 「가운데 카메라로 시작해요」 |
| 성장 | 탭 | 「내 진도」 / 「2022 개정 교육과정 · 중1」. 유리 알약 학년 선택(선택은 흰색 + 진파랑 글자). 유리 칸 2개: 「끝낸 단원 n / N」(진행률 100인 단원 수), 「정답률」(`stats.accuracy`). 시작 전이면 「숙제를 찍으면 그 단원부터 채워져요」를 설명 줄에 | 단원 목록 |
| 설정 | 탭 | 「설정」. 프로필 줄(사진 또는 이름 첫 글자, 「이름님」, 학년 · 학교). 학생이면 유리 카드 「학생 코드」 + 흰 「복사」 | 알림·계정 등 기존 묶음 |
| 분석 결과 | 흐름 | 머리줄 「분석 결과」. 「분석 완료」 + 결론 문장(지금 결과 화면의 큰 제목). 유리 칸: 「약한 유형」, 「추천 훈련」. 흰 「비슷한 문제 풀기」(지금 본문의 주 버튼을 무대로 올림) | 풀이 사진, 막힌 곳 설명, 추출한 문제 등 |
| 분석 중 | 흐름 | 머리줄 「분석 중」. 지금의 진행 문구를 결론 자리에 | 기존 진행 표시 |
| 문제 풀이 | 흐름(낮게) | 머리줄(세트 제목), 진행 「3 / 5」 + 흰 막대, 주제 한 줄 | 문제 카드, 보기, 파란 유리 「제출하기」 등 기존 |
| 업로드 | 흐름 | 머리줄 「숙제 올리기」. 설명 문장(지금의 안내 문구) | 사진 칸, 앨범 버튼, 파란 유리 분석 버튼 |
| 세트 결과 | 흐름 | 머리줄 「훈련 결과」. 결과 문장(지금 화면의 큰 결과 문구) + 유리 칸(맞힌 수 등 화면에 이미 있는 숫자) + 흰 주 버튼(지금의 주 버튼) | 문제별 결과 |
| 학습 통계 | 흐름 | 머리줄 「학습 통계」(학부모·선생님은 지금처럼 「학생 학습 통계」). 유리 칸에 화면에 이미 있는 대표 숫자 2개 | 차트 등 기존 |

### 3.2 학부모 (탭: 홈, 설명, 이번 주, 진도, 설정)

| 화면 | 무대 | 무대 내용 | 무대 아래 |
|------|------|-----------|-----------|
| 홈 (`ParentHomeScreen`) | 탭 | 「안녕하세요, 이름님」 / 「오늘은 이렇게 도와주시면 좋아요」. 자녀 고르기 칩. 유리 카드: 오늘의 부모 코칭(지금 카드의 라벨, 질문, 상황). 코칭이 없으면 지금 문구 「(자녀)가 문제를 풀면, 대화용 코칭 질문이 여기에 표시됩니다.」. 유리 칸 2개: 「이번 주 정답률」(`stats.accuracy`, 변화량이 0이 아니면 작은 글씨로 +n%), 「푼 문제」(`stats.totalProblems`) | 「틀린 문제, 이렇게 도와주세요」, 「오늘 할 일」 |

| 설명 (`ParentExplainScreen`) | 탭 | 「이해하기 쉬운 설명」 / 「학부모가 자녀에게 바로 설명할 수 있도록 정리했어요.」. 자녀 고르기 칩 | 틀린 문제 카드 목록, 빈 안내 |

| 이번 주 (`ParentReportScreen`) | 탭 | 「(주 라벨) · 부모 가이드」 / 기간(`report.period`). 자녀 고르기 칩. 코칭 카드가 있으면 유리 카드로 | 이번 주 체크리스트, 학습 루프 · 부모 역할, 단원 이해도 |
| 진도 (`StudentProgressScreen`, 학부모 보기) | 탭 (선생님 반진도에서 「진도 보기」로 밀어서 열면 흐름: 머리줄 「교육과정 진도」 + 뒤로가기, 그 아래는 같은 내용) | 학생 성장 무대와 같은 짜임새. 「교육과정 진도」 / 「단원을 눌러 자녀에게 어떻게 도와줄지 확인하세요」. 자녀 고르기 칩, 학년 알약, 유리 칸 2개(끝낸 단원, 정답률). 오른쪽 자리에 「학생 학습 통계」 | 단원 목록(눌러서 부모 가이드) |
| 설정 | 탭 | 학생 설정과 같은 무대. 자녀가 연결돼 있으면 지금처럼 자녀 고르기 칩(무대 위). 학생 코드 카드는 없다 | 「학생 연결 관리」 등 기존 묶음 |

### 3.3 선생님 (탭: 홈, 학생, 반진도, 설정)

지금 실제 선생님 계정은 「교사 계정 준비 중」 화면에서 막히고, 이 탭들은 게스트 선생님으로만 들어온다. 그래도 같은 규칙으로 맞춘다.

| 화면 | 무대 | 무대 내용 | 무대 아래 |
|------|------|-----------|-----------|
| 홈 (`TeacherHomeScreen`) | 탭 | 「안녕하세요, 이름님」(이름 없으면 「선생님」) / 기관 이름(있을 때만). 유리 칸 3개: 「담당 학생」, 「즉시 관리」(n명), 「반 평균」(n%) — 지금 보라 상자의 숫자 그대로. 흰 「학생 추가」(지금의 학생 추가 줄, 학생 코드 입력으로 이동) | 「즉시 관리 필요」 경고, 「전체 학생 현황」 |
| 학생 (`TeacherStudentDetailScreen`) | 탭 | 고른 학생 이름(제목) / 학생 코드(설명), 이름 첫 글자 원. 유리 칸 2개: 「이번 주 정답률」, 「푼 문제」. 고른 학생이 없으면 제목 「학생」, 설명 「홈 탭에서 학생을 선택하면 상세 현황을 볼 수 있습니다.」 | 약점 개념, 최근 피드백 |
| 반진도 (`TeacherClassProgressScreen`) | 탭 | 「반 진도 현황」(설명 없음) | 단원 평균, 지도 추천, 선택 학생(「진도 보기」) |
| 설정 | 탭 | 학부모 설정과 같다(자녀 고르기 칩은 지금처럼 없음) | 기존 묶음 |

### 3.5 라이트 앱 (`LiteHomeScreen`, 별도 빌드)

| 화면 | 무대 | 무대 내용 | 무대 아래 |
|------|------|-----------|-----------|
| 라이트 첫 화면 | 탭(탭바 없음) | 「우열 라이트」 / 「풀이 사진만 올리면 분석 · 유사문제 · PDF까지 한 번에」. 흰 「카메라로 풀이 촬영」 | 「앨범에서 선택」(테두리 버튼) |

라이트 앱이 여는 분석·풀이 화면은 학생 표의 흐름 무대를 그대로 쓴다.

무대로 올리는 문구와 숫자는 그 화면이 지금 보여주는 것만 쓴다. 새로 지어내지 않는다.

## 4. 코드 구조

- `widgets/page_stage.dart` (새 파일): `PageStage.tab({title, subtitle, children})`, `PageStage.flow({title, onBack, eyebrow, headline, children})`. 배경, 여백, 제목 스타일, 뒤로가기를 한곳에서 그린다. 홈의 `HomeStage`는 배경과 글자 스타일을 이 파일과 공유한다(동작은 그대로).
- 무대 위 유리 칸(라벨 + 숫자)은 홈의 통계 칸과 같은 위젯으로 모은다. 칸 수는 2개 또는 3개(선생님 홈).
- 흐름 화면은 `Scaffold`의 `AppBar`를 없애고 무대 머리줄로 대신한다. 뒤로가기는 지금과 같은 동작(`Navigator.maybePop`).
- 학부모 탭의 공통 틀(`ParentLinkedScrollView`, `widgets/parent_tab_scaffold.dart`)이 지금 맨 위에 그리는 자녀 고르기 칩(`StudentPicker`)은 무대 안으로 옮긴다. `StudentPicker`에 무대용 모양(2.1: 유리 알약 + 흰 글자, 유리 원 자녀 추가)을 더한다. 칩을 눌러 여는 시트와 고르는 방식은 그대로.
- 연결 안 된 학부모 안내(`GuardianLearningGate`)도 `PageStage.tab`으로 그린다.
- 디자인 규칙 테스트(`test/design_rules_test.dart`)의 `GlassSurface(` 허용 목록에 `page_stage.dart`와 무대를 쓰는 화면·위젯을 넣는다(무대 위 유리는 이제 모든 역할의 화면에서 허용).

## 7. 내 판단으로 정한 것 (검토자 질문에 대한 답)

- **상태바와 스크롤**: 무대가 보이는 동안 상태바 글자는 흰색(`PageStage`가 `AnnotatedRegion<SystemUiOverlayStyle>`을 가진다). 무대가 스크롤되어 사라지면 홈처럼 `GlassStatusBarBand`가 나타나고 글자는 검정이 된다. 훈련·성장의 `GlassScrollEdge`는 이 띠로 바꾼다(홈과 같은 동작).
- **흐름 화면 뒤로가기**: 무대와 함께 스크롤되지 않고 왼쪽 위에 떠 있는 유리 원으로 고정한다(떠 있는 층이라 유리 규칙에 맞음). 무대가 사라지면 작은 제목은 상태바 띠에 보인다.
- **오른쪽 버튼 자리**: `PageStage`에 오른쪽 유리 원 자리(`trailing`)를 둔다. 풀이 화면의 ⋯ 메뉴(새 문제, 더 어려운 문제, PDF)와 라이트 모드 PDF 버튼, 성장 화면의 학습 통계 버튼이 여기로 간다.
- **설정**: 무대의 프로필 사진은 지금처럼 눌러서 사진을 바꿀 수 있고(편집 표시 유지), 「기본 정보 수정」은 무대 안 흰 작은 버튼으로 둔다. 역할 칩과 게스트 안내는 무대 아래 첫 줄에 둔다.
- **분석**: 「비슷한 문제 풀기」는 쓸 수 있는 상태(결과 완료, 또는 지금처럼 유사 문제가 먼저 준비된 때)에 무대의 흰 버튼이다. 「홈으로」, 「유사문제 PDF로 받기」는 무대 아래 테두리 버튼으로 둔다. 「분석 중」 → 「분석 결과」는 같은 화면에서 바로 바뀐다.
- **불러오는 중·오류·빈 상태**: 무대(제목과 설명)는 항상 그리고, 스켈레톤·오류·빈 안내는 무대 아래에 둔다.
- **훈련 무대 카드**: 지금 화면의 위쪽 카드 분기를 그대로 무대로 올린다. 복습 세트 카드면 흰 「5문제 세트로 복습」, 이어서 할 세트가 있으면 흰 「이어서 복습하기」, 피드만 있으면 「풀 문제 N개가 준비됐어요」. 기록은 있는데 훈련할 게 없으면 「막힌 문제를 다 풀었어요.」 유리 칸은 「풀 문제」(피드 문제 수)와 「다시 맞힘」(`relearnedCount`, N건). 카드 본문에는 다시 맞힘 숫자를 다시 쓰지 않는다.
- **숫자 정의**: 「끝낸 단원 n / N」의 N은 지금 고른 학년 구간의 단원 수. 학습 통계 유리 칸은 「정답률」과 「숙련도 점수」.
- **풀이 무대**: 주제 줄은 `problemSet.title` 한 줄(넘치면 말줄임). `learningGoal`은 무대 아래 그대로. 진행 표시는 「3 / 5」. 첫 화면 기준: 390×844에서 문제 카드 위쪽이 보이고, 문제 글이 아래 제출 막대보다 위에서 시작한다.
- **더 넣는 화면**: 「연습 준비」(`PracticeGeneratingScreen`)도 흐름 무대를 쓴다. 쓰지 않는 `HomeScreen`, `ParentGrowthScreen`, `StudentCodeScreen`은 그대로 둔다.
- **학부모·선생님 홈**: 학생 홈의 큰 앱 아이콘·날짜 무대(`HomeStage`)는 학생 홈에만 두고, 학부모·선생님 홈은 인사 문장을 제목으로 쓰는 탭 무대로 한다. 학생 홈은 「오늘 할 공부」가 중심이라 무대가 크고, 학부모·선생님 홈은 코칭·숫자가 중심이라 다른 탭과 같은 높이가 맞다고 봤다.
- **역할 색**: 무대 위는 역할과 상관없이 파랑·흰색·유리만 쓴다. 학부모 코칭 카드의 초록 강조, 선생님 홈의 보라 상자는 무대로 올라가면서 유리 카드·유리 칸이 된다. 무대 아래의 역할 색(설정의 역할 칩, 「즉시 관리 필요」의 경고 색 등)은 그대로 둔다.
- **학부모 숫자**: 지금 홈의 한 줄 요약(「자녀 · 이번 주 n% · n문제」)을 유리 칸 2개로 나눈다. 숫자는 같은 `stats` 값이다.
- **선생님 학생 추가**: 무대의 흰 「학생 추가」는 지금 줄과 같은 곳(학생 연결 화면)으로 간다.
- **코칭 카드의 「채점 포인트」**: 지금 카드에 있는 내용이라 빼지 않는다. 무대 유리 카드 안에서 한 겹 더 옅은 칸(흰색 14% 정도)에 그대로 둔다.
- **불러오는 중·오류일 때 제목**: 데이터가 와야 생기는 제목은 그 전까지 탭 이름을 쓴다. 이번 주는 「이번 주 할 일」(지금 안내 화면 제목), 설명은 없음. 선생님 홈은 이름이 세션에 있으니 「안녕하세요, 이름님」을 바로 쓰고 기관 이름만 나중에 붙는다. 유리 칸은 데이터가 올 때까지 그리지 않는다(0으로 채우지 않는다).
- **선생님 학생 탭 새로고침**: 지금은 처음 한 번만 불러와서, 홈에서 학생을 바꾸면 이름만 바뀌고 숫자는 그대로다. 무대에 이름과 숫자가 나란히 서면 서로 다른 학생 것이 보이게 되므로, 고른 학생이 바뀌면 다시 불러오게 고친다(동작 변경은 이것 하나).
- **라이트 앱**: 「카메라로 풀이 촬영」이 주 동작이라 무대의 흰 버튼으로 올리고, 「앨범에서 선택」은 무대 아래 테두리 버튼으로 둔다.
- **로그인 세션 알림**: 이 문서가 승인되면 로그인·온보딩 세션에 메시지로 무대 규칙과 맡긴 막는 화면 두 개를 알린다.
