# 우열 디자인 리뉴얼: Liquid Glass

- 날짜: 2026-10-17
- 상태: 승인 (2026-10-17)
- 브랜치: `renovation`
- 범위: Flutter 학생 앱 중심. 학부모·선생님 화면은 유리 규칙과 탭바만 맞춘다.

## 1. 목표

디자인 방향을 하나로 고정해서 더는 흔들리지 않게 한다. 표면 스타일은 Apple Liquid Glass를 쓴다.

7~8월에 유리, 뉴모피즘, 플랫 유리를 오가며 되돌리기를 15번 넘게 했다. 원인은 유리를 콘텐츠 카드에 발랐기 때문이다. 콘텐츠 위의 유리는 뒤에 색이 있어야 유리처럼 보인다. 그래서 알록달록한 배경화면을 깔면 공부 앱으로는 시끄러웠고, 배경을 빼면 뿌연 회색판이 됐다(8/21 `4daea6f` → `24ba2f1`). 이 스펙은 유리를 쓰는 **위치**를 규칙으로 못 박아서 이 충돌을 없앤다.

**대상**: 중학생. 주 플랫폼은 폰 앱(iOS, Android)이고, 웹은 개발 미리보기와 보조 용도다.

**성공 기준**

1. 모든 화면의 모든 표면을 3장의 유리 규칙만으로 결정할 수 있다.
2. 화면마다 파란 채움 버튼이 하나다(4장 버튼 규칙).
3. 첫 로그인부터 첫 숙제 찍기까지 다음 행동이 늘 하나로 보인다.
4. 웹(Chrome)에서 첫 프레임이 멈추지 않는다(`f33a746`의 멈춤이 다시 생기지 않는다).
5. `flutter analyze`에서 에러가 0개다.

## 3. 유리 규칙

판단 기준은 하나다. **콘텐츠 위에 떠 있으면 유리, 아니면 흰 카드.** 예외는 홈 상단의 파란 무대 하나뿐이다.

| 요소 | 표면 |
|------|------|
| 콘텐츠 카드, 리스트 줄, 통계, 입력칸 | 흰 카드 `#FFFFFF`, 테두리 `#EFEFF1` 1px, 모서리 16~18px, 그림자 없음 |
| 화면 배경 | 안개색 `#EEF3F8` 단색 |
| 아래 탭바 | 맑은 유리 |
| 탭바 가운데 카메라 | 파란 유리 |
| 스크롤하면 생기는 상단 | 흐림 가장자리(위는 진하고 아래로 사라짐) + 가운데 작은 제목 |
| 아래에서 올라오는 시트, 팝업 | 맑은 유리 |
| 사진 위 라벨, 버튼 (분석 화면 등) | 맑은 유리 |
| **예외**: 홈 파란 무대 위 카드 | 무대용 유리 |

**금지**: 배경화면 이미지, 큰 색 번짐(blob), 콘텐츠 위의 `GlassPanel`, 파란 무대를 홈 밖에서 쓰기, 노란색 번짐(파랑과 섞여 회갈색이 된다).

**유리 프리셋** (Flutter에서 `BackdropFilter`로 구현)

| 프리셋 | 채움 | 흐림 | 테두리 | 그림자 |
|--------|------|------|--------|--------|
| 맑은 유리 | 흰색 30% | 14 (채도 1.8배, 가능하면) | 흰색 66% 1px + 위쪽 안쪽 하이라이트 | `0 8 24` 남색 14% |
| 무대용 유리 | 흰색 14% | 16 | 흰색 38% 1px | `0 10 26` 남색 22% |
| 파란 유리 | `#2A72E5` 88% | 10 | 흰색 28% 1px + 위쪽 안쪽 하이라이트 | `0 8 18` 파랑 32% |

진짜 굴절(렌즈) 효과는 이번 범위가 아니다. 모든 플랫폼에서 흐림 기반으로 통일한다. 웹에서 `HtmlElementView`로 유리를 만들지 않는다.

## 4. 버튼

| 종류 | 모양 | 쓰는 곳 |
|------|------|---------|
| 파란 유리 주 버튼 | 파란 유리 + 흰 글씨, 높이 50~52, 완전 둥근 모서리 | 탭바가 없는 전체 화면 흐름(풀이, 분석, 업로드)에서 화면당 하나 |
| 흰 주 버튼 | 흰색 + 파란 글씨 | 홈 파란 무대 위에서만 (「이어서 풀기」) |
| 연파랑 주 버튼 | `#E8F1FC` + `#1E46AA` 글씨 | 탭 화면(홈 아래쪽, 훈련, 성장, 설정)의 본문 |
| 보조 | 흰 카드 버튼 또는 글자 링크 | 어디서나 |

탭 화면에서는 가운데 카메라가 그 화면의 유일한 파란 채움이다. 그래서 탭 화면 본문에는 파란 채움 버튼을 두지 않는다.

## 5. 내비게이션

**학생 탭바**: 홈 · 훈련 · [찍기] · 성장 · 설정

- 기존 「업로드」 탭 자리가 가운데 카메라가 된다.
- 카메라를 누르면 업로드 흐름을 **전체 화면으로** 연다. 탭 전환이 아니다. 갤러리 선택도 그 흐름 안에 있다.
- 훈련 탭의 새 항목 배지는 그대로 둔다.

**학부모** (홈 · 설명 · 이번 주 · 진도 · 설정)와 **선생님** (홈 · 학생 · 반진도 · 설정)은 같은 유리 탭바를 쓰고, 가운데 카메라는 없다.

**탭바 치수**

- 떠 있는 알약 모양이다. 좌우 여백 12, 아래 여백 16 + 안전 영역, 높이 64.
- 선택된 탭: 파란 아이콘·글자 + 파랑 12% 알약 배경.
- 가운데 카메라: 58px 원, 탭바보다 30px 위로 솟음, 흰 테두리 3px, 아래 글자 「찍기」.
- 콘텐츠는 탭바 아래까지 스크롤된다(유리 아래로 비쳐 보이게).

## 6. 홈 (학생)

상태는 지금 코드의 조건을 그대로 쓴다.

- **처음 / 다시**: `hasHistory`(제출 기록이 있거나 푼 문제가 1개 이상)로 가른다. 지금의 `_FirstTimeHome` / `_ReturningHome`과 같다.
- **게스트**: `authSession.isGuest`. 처음 / 다시와 별개다. 게스트이면 사용자 줄을 게스트용으로 바꾸고, 무대 카드 아래에 가입 안내 줄을 붙인다(6.4).

### 6.1 상단 파란 무대

- 배경: 165° 그라데이션 `#5EB7EB` → `#2A72E5` → `#1E46AA`, 아래 모서리 32. 번짐 장식은 없다.
- 오른쪽 위: 앱 아이콘(흰 모서리를 뺀 버전) 108px, 8° 기울임, 그림자.
- 왼쪽 위, 위에서부터:
  1. 날짜: 「10월 17일 토요일」 (13, 굵기 600, 흰색 86%)
  2. 사용자 줄: 프로필 사진 40px(없으면 이름 첫 글자) + 이름 「지민님」(17, 700) + 아래 「중1 · 한빛중학교」(12.5, 600, 흰색 80%)
     - 이름은 `displayName` + 「님」, 아래 줄은 `grade` · `organizationName`이다. 없는 값은 빼고, 둘 다 없으면 줄을 숨긴다.
     - 길면 말줄임(…)으로 자르고, 아이콘과 겹치지 않는다.
  3. 연속 칩: `streakWeeks`가 1 이상이고 다시 온 상태일 때만 「N주 연속」(불꽃 아이콘, 무대용 유리).
- 인사 문장 (22, 700, 흰색):
  - 처음: 「오늘은 한 장만 올려도 돼요」
  - 다시 왔을 때: 「어제 막힌 곳부터 이어가요」
- 「우열」 글자 워드마크는 쓰지 않는다.

### 6.2 처음 들어왔을 때 (기록 없음)

- 무대 안: 무대용 유리 카드에 3단계를 넣는다.
  1. 숙제 한 장 찍기 · 풀다가 막힌 문제 그대로
  2. 막힌 곳 짚기 · 어디서 틀렸는지 한 줄로
  3. 이어서 풀기 · 비슷한 문제로 다시 확인
- 그 아래 글자 링크 「앨범에서 사진 고르기」를 둔다.
- 무대 밑: 「이렇게 짚어줘요 · 예시」 카드. 예시는 분과 시간 단위를 섞은 풀이에 빨간 원을 친 것이다.
- 가운데 카메라 위 말풍선(맑은 유리): 「여기를 눌러 숙제 한 장 찍어요」. 첫 업로드 전까지만 보인다.
- 본문의 「숙제 올리기」 버튼은 없앤다. 카메라가 그 역할을 한다.

### 6.3 다시 왔을 때

- 무대 안: 무대용 유리 미션 카드(단원, 남은 문제 수, 제목, 진행 막대, 흰 주 버튼 「이어서 풀기」) + 통계 유리 칸 2개(정답률, 해결한 문제).
- 무대 밑: 「최근」 리스트. 흰 카드 줄에 숙제 썸네일, 제목, 날짜·문제 수, 상태 칩(「N문제 남음」 연파랑, 「다 풀었어요」 연초록)을 둔다.

### 6.4 게스트

- 사용자 줄: 사람 아이콘(무대용 유리 원) + 「반가워요」 / 「둘러보는 중」.
- 무대 카드(3단계 카드 또는 미션 카드) 아래 무대용 유리 줄: 「둘러보는 중이에요. 가입하면 기록이 남아요.」 + 「가입하기」. 기존 `_GuestSaveBanner`를 대체한다.

## 7. 빈 상태 (첫 로그인)

**훈련 탭**

- 제목 「훈련」, 설명 「막힌 개념만 모아서 다시 풀어보는 곳이에요.」
- 빈 카드: 연파랑 원 아이콘 + 「아직 훈련할 문제가 없어요」 + 「숙제를 찍으면 막힌 개념이 여기에 모여요.」
- 「이런 식으로 쌓여요 · 예시」: 흐린 점선 예시 줄 2개
- 아래 안내: 「가운데 카메라로 시작해요」
- 기록은 있는데 훈련할 게 없을 때: 「막힌 문제를 다 풀었어요. 새로 막히면 여기에 모여요.」
- 기존 「아직 훈련할 항목이 없습니다」(합니다체, 「맞춤 추천」 말투)는 없앤다.

**성장 탭**

- 제목 「내 진도」(기존 「내 진도 현황」), 설명 「2022 개정 교육과정 · 중1」
- 중1 · 중2 · 중3 구간 선택(흰 알약)
- 안내 카드: 「0 / N 단원」 + 「숙제를 찍으면 그 단원부터 채워져요.」
- 교육과정 데이터의 단원을 전부 보여주고, 각 줄은 「시작 전」과 빈 진행 막대로 둔다.

  - 사용자 줄: 이름·학교가 길 때 말줄임, 값이 없을 때 줄 숨김
  - 연속 칩 표시 조건
  - 학생 탭바: 5칸, 가운데 카메라를 누르면 업로드 흐름이 열림
- iOS 시뮬레이터와 Android 에뮬레이터에서 확인할 화면: 첫 로그인(홈, 훈련, 성장), 다시 온 홈, 게스트, 긴 이름, 스크롤 때 탭바와 상단 흐림 아래로 콘텐츠가 비치는지
- 웹(Chrome localhost): 첫 프레임이 바로 그려지는지
- 오프라인 PDF 한글 출력(10장)

## 13. 확정된 가정

검토 때 아래 네 가지를 그대로 가기로 했다.

1. 가운데 카메라는 탭 전환이 아니라 업로드 흐름을 전체 화면으로 연다.
2. 탭 화면 본문의 주 버튼은 연파랑 채움이다. 파란 유리 주 버튼은 탭바가 없는 흐름에서만 쓴다.
3. 다시 온 홈의 「어제 막힌 곳부터 이어가요」는 마지막 활동이 어제가 아니어도 그대로 쓴다(지금 코드와 같다).
4. 카메라 위 말풍선은 첫 업로드 전까지만 보인다.
